# Earn Kenya Rewards

EARNPESA 🇰🇪 — Website Design & Development Brief



Brand: EARNPESA

Tagline: Connect. Refer. Earn.

Theme: Red + Gold + White

Target: Kenya-first, mobile-first digital rewards and opportunities platform.



🚀 Core Concept



Build EARNPESA as a modern, professional digital opportunities marketplace where users can discover legitimate campaigns, complete online activities, refer others and earn verified rewards.



Businesses can also create campaigns to reach customers through referrals, surveys, sponsored content, videos, promotions and affiliate offers.



Business model:

Businesses fund campaigns → EARNPESA tracks verified actions → eligible users receive rewards.



The platform should not be based on deposits, guaranteed returns or recruitment-only earnings.

---



⚡ Technical Direction



Build it mobile-first, fast, secure and scalable.



Recommended architecture:



Frontend: React / Next.js

Backend: Node.js / NestJS

Database: PostgreSQL

Storage: Cloud storage

Payments: M-Pesa-ready architecture

API: Secure REST/API architecture



Use role-based access:



User | Business | Admin | Super Admin



The system should be designed so additional payment providers, survey providers, advertisers and campaign partners can be added later without rebuilding the platform.
